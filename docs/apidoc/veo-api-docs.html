Veo 视频生成 API

Google Veo 模型，支持文生视频、首尾帧模式和多图参考模式，异步提交 + 轮询查询。

快速开始

# 1. 提交任务（JSON 方式）
curl -X POST https://apiai-tudou.net/v1/videos \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo_3_1",
    "prompt": "一只可爱的小猫在花园里玩耍",
    "size": "1280x720"
  }'

# 2. 轮询结果
curl https://apiai-tudou.net/v1/videos/{task_id} \
  -H "Authorization: Bearer $API_KEY"

可用模型

模型模式速度画质图片数量说明
veo_3_1多图参考标准标准0 或 1~3基础参考图 / 文生视频
veo_3_1-hd多图参考标准高清0 或 1~3参考图模式的高清版
veo_3_1-fl首尾帧标准标准1~2首尾帧模式，1 张 = 仅首帧，2 张 = 首尾帧
veo_3_1-hd-fl首尾帧标准高清1~2首尾帧模式的高清版
veo_3_1-fast-fl首尾帧快速标准1~2首尾帧模式的快速版
veo_3_1-fast-fl-hd首尾帧快速高清1~2首尾帧模式的快速高清版

命名规则

模型名由 veo_3_1 加可选后缀组合而成：

后缀含义
（无后缀）标准速度、标准画质
-hd高清画质
-fl首尾帧模式（first / last frame），需传入 1~2 张图作为首帧和尾帧
-fast-fl快速 + 首尾帧模式
-fast-fl-hd快速 + 首尾帧 + 高清画质
不含 -fl 的模型（veo_3_1 / veo_3_1-hd）为多图参考模式， 可传 1~3 张参考图引导视频风格，不传图时即为文生视频。

模型选择指南

  • 文生视频：选非 -fl 模型（如 veo_3_1），不传图片字段
  • 参考图模式（图生视频）：选非 -fl 模型，传 1~3 张参考图
  • 首尾帧模式（图生视频）：选 -fl 结尾的模型，传 1~2 张图
  • 追求速度：选带 -fast 的模型
  • 追求画质：选带 -hd 的模型

通用说明

端点

方法路径说明
POST/v1/videos提交视频生成任务
GET/v1/videos/{task_id}查询任务状态

请求头

参数值说明
AuthorizationBearer YOUR_API_KEY必填
Content-Typeapplication/json 或 multipart/form-dataPOST 时必填

请求参数

参数类型必填说明
modelstring是模型名称，详见 可用模型
promptstring是文本提示词
sizestring否视频尺寸，如 1280x720（横屏）、720x1280（竖屏）
imagesstring[]否参考图 URL 数组，最多 3 张（JSON 方式使用此字段）
input_reference[]可重复否参考图 URL，最多 3 张（表单方式使用此字段，同一字段名可重复多次）
JSON 与表单二选一即可。文生视频时不传图片字段。
图片顺序约定：首尾帧模式 — 第 1 张为首帧，第 2 张为尾帧（仅 1 张时只指定首帧）； 参考图模式 — 最多 3 张，顺序为参考图 1、2、3。

响应参数

参数类型说明
idstring任务 ID
statusstringqueued / processing / completed / failed
progressnumber进度 0~100
video_urlstring视频直链（仅 completed 时返回）
errorobject错误信息（仅 failed 时返回），含 message、code

状态流转

queued → processing → completed ↘ failed

提交任务

JSON 方式（推荐）

curl -X POST "https://apiai-tudou.net/v1/videos" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo_3_1-fl",
    "prompt": "广告",
    "size": "1280x720",
    "images": [
      "https://example.com/first.png",
      "https://example.com/second.jpg"
    ]
  }'

表单方式

curl -X POST "https://apiai-tudou.net/v1/videos" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=veo_3_1-fast-fl" \
  -F "prompt=广告" \
  -F "size=1280x720" \
  -F "input_reference[]=https://example.com/first.png" \
  -F "input_reference[]=https://example.com/second.jpg"

完整调用示例

Python（JSON 方式）

import requests
import time

API_BASE = "https://apiai-tudou.net"
API_KEY = "YOUR_API_KEY"
HEADERS = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json",
}

# 1. 提交任务
resp = requests.post(
    f"{API_BASE}/v1/videos",
    headers=HEADERS,
    json={
        "model": "veo_3_1",
        "prompt": "一只可爱的小猫在阳光下玩耍，电影级画质",
        "size": "1280x720",
    },
)
task = resp.json()
task_id = task["id"]
print(f"任务已创建: {task_id}")

# 2. 轮询状态
while True:
    resp = requests.get(
        f"{API_BASE}/v1/videos/{task_id}",
        headers={"Authorization": f"Bearer {API_KEY}"},
    )
    data = resp.json()
    status = data["status"]
    progress = data.get("progress", 0)
    print(f"状态: {status}, 进度: {progress}%")

    if status == "completed":
        print(f"生成成功！视频地址: {data['video_url']}")
        break
    elif status == "failed":
        print(f"生成失败: {data['error']['message']}")
        break

    time.sleep(5)
