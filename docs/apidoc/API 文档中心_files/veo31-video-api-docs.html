Veo3.1 视频生成 API（土豆 API）

Google Veo3.1 引擎，支持文生视频与图生视频，可选 720p / 1080p 分辨率，最多 3 张参考图。异步任务模式，提交后轮询查询状态，完成后直接获取视频 URL。

快速开始

# 1. 提交文生视频任务（JSON body）
curl -X POST https://api.ai-tudou.net/v1/videos/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"veo3.1-720p","prompt":"一只橘猫在阳光草地上追蝴蝶，温暖治愈","duration":4,"aspect_ratio":"9:16","resolution":"720p"}'

# 2. 轮询任务状态（task_id 为上一步返回 data.id）
curl https://api.ai-tudou.net/v1/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"

# 3. 任务 completed 后，直接从 data.result.video_url 下载视频
curl -L "VIDEO_URL" -o out.mp4
基址：https://api.ai-tudou.net。提交端点为 /v1/videos/generations，轮询端点为 /v1/tasks/{task_id}。请求体为 JSON（application/json），不是 multipart 表单。

认证

所有接口均需在请求头携带 API Key：

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

可用模型

模型名分辨率说明
veo3.1-720p720p720p 入口，出片分辨率固定为 720p
veo3.1-1080p1080p1080p 入口，出片分辨率固定为 1080p
模型名后缀即分辨率，一一对应，不可覆盖。
  • 请求 veo3.1-720p 时，resolution 参数必须传 "720p"；
  • 请求 veo3.1-1080p 时，resolution 参数必须传 "1080p"；
  • 后缀与 resolution 不一致会被渠道拒绝。

参数取值

参数取值默认
duration4 / 6 / 8（秒）8
aspect_ratio16:9 / 9:1616:9
resolution720p / 1080p由模型名后缀决定，必须与后缀一致
reference_modeframe / imageframe
渠道需先加入对应模型名。在土豆 API 的渠道配置里把你要用的模型名（veo3.1-720p / veo3.1-1080p）加入模型列表，否则会返回「分组下模型 xxx 无可用渠道」。

通用参数

参数类型默认值必填说明
modelstring—是填 veo3.1-720p 或 veo3.1-1080p
promptstring—是视频描述文本
resolutionstring—是分辨率，必须与模型名后缀一致（720p / 1080p）
durationint8否时长（秒）：4 / 6 / 8，越界自动夹紧到最近合法值
aspect_ratiostring16:9否比例：16:9（横屏）/ 9:16（竖屏）
imagesstring[]—否图生视频参考图 URL 数组；frame 模式最多 2 张，image 模式最多 3 张
reference_modestringframe否参考模式：frame（首尾帧引导）/ image（多图风格参考，最多 3 张），详见 多图参考模式
generate_audiobooltrue否是否生成音频
negative_promptstring—否负向提示词
除 model / prompt / resolution 外其余参数均可省略，服务端按默认值补齐。images 留空即文生视频，附上 URL 即图生视频。

提交视频任务

POST /v1/videos/generations   application/json

提交后立即返回任务 id，无需保持长连接，通过轮询获取结果。

文生视频

curl -X POST https://api.ai-tudou.net/v1/videos/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo3.1-1080p",
    "prompt": "城市夜景延时，赛博朋克风格，流光溢彩",
    "duration": 8,
    "aspect_ratio": "16:9",
    "resolution": "1080p"
  }'

提交响应

{
  "code": 200,
  "message": "ok",
  "data": {
    "id": "AbC123DeFgH"
  }
}
返回的 data.id 用于后续轮询查询。

图生视频

在请求体中加入 images 数组（图片 URL）即进入图生视频模式。默认 frame 模式最多 2 张，作为首尾帧引导生成。

curl -X POST https://api.ai-tudou.net/v1/videos/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo3.1-720p",
    "prompt": "让画面动起来，加入微风与光影流动",
    "duration": 4,
    "aspect_ratio": "9:16",
    "resolution": "720p",
    "images": [
      "https://cdn.phototourl.com/free/2026-06-22-f62848fd-53ae-4ce1-ac51-45da9386b60b.png"
    ]
  }'
图片需为可公网访问的 URL。服务端会下载并上传到上游作为参考图，单张最大 10MB，超限或不可达会返回 400。

多图参考模式

需要 3 张参考图、且希望成片更贴合输入图风格时，把 reference_mode 设为 "image"，images 最多可传 3 张。

reference_mode语义images 上限
frame（默认）首尾帧引导动画，图作为视频的起点/终点2 张
image多图风格参考，成片更贴合输入图的风格与内容3 张
 
curl -X POST https://api.ai-tudou.net/v1/videos/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo3.1-1080p",
    "prompt": "保持画面风格，让场景动起来，加入微风与光影流动",
    "duration": 6,
    "aspect_ratio": "16:9",
    "resolution": "1080p",
    "reference_mode": "image",
    "images": [
      "https://cdn.example.com/ref1.png",
      "https://cdn.example.com/ref2.png",
      "https://cdn.example.com/ref3.png"
    ]
  }'
reference_mode 只在图生视频（images 非空）时生效；文生视频传不传都不影响结果。非法值会回落到 frame。

查询状态与下载

查询任务状态

GET /v1/tasks/{task_id}

curl https://api.ai-tudou.net/v1/tasks/AbC123DeFgH \
  -H "Authorization: Bearer YOUR_API_KEY"

状态说明

status含义
submitted已入队，等待处理
processing生成中，progress 字段为 0–100
completed完成，从 data.result.video_url 获取视频地址
failed失败，见 data.error.message

状态流转

submitted → processing → completed ↘ failed

查询响应示例（生成中）

{
  "code": 200,
  "message": "ok",
  "data": {
    "id": "AbC123DeFgH",
    "status": "processing",
    "progress": 42
  }
}

查询响应示例（完成）

{
  "code": 200,
  "message": "ok",
  "data": {
    "id": "AbC123DeFgH",
    "status": "completed",
    "progress": 100,
    "result": {
      "videos": [
        { "url": ["https://cdn.example.com/out/AbC123DeFgH.mp4"] }
      ],
      "video_url": "https://cdn.example.com/out/AbC123DeFgH.mp4"
    }
  }
}
完成后无需额外的 /content 端点，data.result.video_url 即为可直接下载/播放的 MP4 地址。data.result.videos[0].url 是同一地址的数组形式，兼容旧客户端。
建议提交后等待 10–20 秒再首次查询，之后每 5–10 秒轮询一次。4s/720p 视频通常 1–2 分钟内完成，8s/1080p 耗时更久。结果地址保留时间有限，请及时下载。

完整调用示例

curl — 一行提交（图生视频，9:16，4s，720p）

curl -s -X POST https://api.ai-tudou.net/v1/videos/generations -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" -d "{\"model\":\"veo3.1-720p\",\"prompt\":\"the scene comes alive with subtle cinematic motion\",\"images\":[\"https://cdn.phototourl.com/free/2026-06-22-f62848fd-53ae-4ce1-ac51-45da9386b60b.png\"],\"duration\":4,\"aspect_ratio\":\"9:16\",\"resolution\":\"720p\"}"

curl — 一行提交（多图参考，3 张，image 模式，1080p）

curl -s -X POST https://api.ai-tudou.net/v1/videos/generations -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" -d "{\"model\":\"veo3.1-1080p\",\"prompt\":\"keep the style, animate the scene\",\"reference_mode\":\"image\",\"images\":[\"https://cdn.example.com/ref1.png\",\"https://cdn.example.com/ref2.png\",\"https://cdn.example.com/ref3.png\"],\"duration\":6,\"aspect_ratio\":\"16:9\",\"resolution\":\"1080p\"}"

Python — 图生视频（异步轮询 + 下载）

import requests, time

API_BASE = "https://api.ai-tudou.net"
HEADERS  = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type":  "application/json",
}

# 1. 提交任务
resp = requests.post(
    f"{API_BASE}/v1/videos/generations",
    headers=HEADERS,
    json={
        "model":           "veo3.1-720p",
        "prompt":          "让画面动起来，加入微风与光影流动",
        "duration":        4,
        "aspect_ratio":    "9:16",
        "resolution":      "720p",
        "reference_mode":  "image",
        "images": [
            "https://cdn.phototourl.com/free/2026-06-22-f62848fd-53ae-4ce1-ac51-45da9386b60b.png"
        ],
    },
)
task_id = resp.json()["data"]["id"]
print(f"任务已提交: {task_id}")

# 2. 等待首次查询
time.sleep(15)

# 3. 轮询状态
while True:
    r = requests.get(f"{API_BASE}/v1/tasks/{task_id}", headers=HEADERS)
    data = r.json()["data"]
    status   = data["status"]
    progress = data.get("progress", 0)
    print(f"状态: {status}  进度: {progress}%")

    if status == "completed":
        video_url = data["result"]["video_url"]
        # 4. 下载视频
        video = requests.get(video_url)
        with open("output.mp4", "wb") as f:
            f.write(video.content)
        print("视频已保存: output.mp4")
        break
    elif status == "failed":
        print(f"生成失败: {data.get('error')}")
        break

    time.sleep(8)

错误码

错误响应遵循 OpenAI 风格：

{
  "error": {
    "message": "Invalid model: veo3.1-720p",
    "type": "invalid_request_error"
  }
}
HTTP 状态码场景说明
400参数错误 / 图片不可达 / 超限模型名非法、resolution 与后缀不匹配、images 超过上限（frame 2 张 / image 3 张）、参考图下载失败等
401鉴权失败API Key 无效或渠道未启用
404任务不存在查询时 task_id 不存在，返回 data.status = "failed"
5xx服务异常上游异常或内部错误，稍后重试
若返回「分组 xxx 下模型 veo3.1-720p 无可用渠道」，说明土豆 API 的渠道模型列表未加入 veo3.1-720p，去管理面板加上即可。
